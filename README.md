# Chasing Powder

## Play the game

### [https://iamstevenhyde.github.io/chasing-powder/](https://iamstevenhyde.github.io/chasing-powder/)

Open that link on any laptop. No GitHub account needed. One person taps
**Host a Game** to start it and reads out the 5-letter join code; everyone else taps
**Join a Game** and enters that code.

Classroom strategy game for MBA 546 (Boise State). Instructor console: admin.html.

Static build staged by deploy-pages-powder.js from Desktop/Classes/MBA/game/powder/.
Do not edit here; edit the source and re-run node deploy-pages-powder.js.
